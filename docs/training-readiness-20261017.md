## 已处理的问题

1. 生成器默认路径从旧 Linux 绝对路径改为项目内 `data/00-origin_data` 和 `data/01-train_data`；训练配置同步本次目录，硬错误默认报错。
2. 原生成器会跳过 482 张 C9277A 多层位图片。当前保留其全部其他任务标签，将单层位标签设为 null，并用 `training_preparation.multi_rack_level` 记录原始层位。底板层文字可识别为 0，多层不会任取一个层位训练。
3. 同一内容图片位于不同路径时，按 SHA256 绑定划分，防止跨 train / val / test 泄漏。
4. 新增 `script/02-checkTrainData.py`，使用真实训练代码检查入库、任务 mask、首批图像增强、PK 组成和跨划分重复，失败返回非零并保存详情。
5. 训练入口原先会无条件删除已有输出，续训同样受影响。现在新训练使用秒级独立目录，显式非空目录拒绝覆盖，续训保留原目录及历史产物。
6. 留一验证将折配置放到训练输出之外；重训和失败重跑保留旧折归档，避免配置被清空或历史权重丢失。
7. 阶段 2 同步恢复最佳模型的 criterion，确保 ArcFace 配置下的测试 loss 使用同一轮类中心。
8. 修复全套回归中暴露的既有 ONNX 导出问题：校验失败保留已有部署包。

## 正式训练前的数据限制

- 有 5 组内容重复图片，其中 2 组标注冲突。它们已绑定同一划分，但未擅自改写冲突标签。需复核 `随机/鸡爪/jizhao_0730_0057(_1).json` 的容器标签，以及 `随机/其余` 和 `随机/琵琶腿` 下 `200_7d80700681fa768a32a9332c06311849.json` 的附件标签。具体原值见 `output/preflight/raw_audit.json`。
- 当前层位输出是单分类，不能预测同时出现的多个层位。如需要多层输出，应另行调整模型、损失和评估；本次选择屏蔽这些图片的层位监督。
- `configs/device_profile.json` 明确注明部分底板可用性、内腔分组和附件支持仍是占位值。必须按业务事实核实，否则分组训练、层位掩码和推理附件过滤的口径可能有误。
- CQ09-i9 和外部未知设备的 val / test 各仅 1 张。外部阈值标定可以执行，但证据不足；默认外部采样比例 25% 也会反复使用仅 9 张外部训练图。
- 泡沫容器只有 3 个正样本，分布为 2 / 0 / 1，验证集无法标定其召回率阈值。玻璃蒸烤盘、脆烤盘没有正样本；“遮挡”按未标注处理，也没有该输出类别的正监督。类别详情见 `output/preflight/class_counts.json`。
- 当前按图片内容与型号划分，没有按视频或拍摄场次分组。相邻帧可能跨划分，独立场次测试仍有必要。

## Linux / NVIDIA GPU 执行顺序

先准备 Python 3.11 环境，安装匹配训练机的 CUDA 版 torch / torchvision，再安装项目依赖。将代码、本次生成目录和预训练权重传到训练机的相同项目相对路径；数据与权重不在 Git 中。

```bash
git submodule update --init third_party/dinov3
python -m pip install -r requirements.txt
python -c "import torch; assert torch.cuda.is_available(); print(torch.cuda.get_device_name(0))"

# 如果直接复制本次生成结果，跳过这一行；重新生成后同步 data.root
python script/01-genTrainData.py

python script/02-checkTrainData.py --config configs/default_oven.yaml
python train.py --config configs/default_oven.yaml --device cuda
```

默认 30 轮、batch 16，每轮 455 步，共 13650 步；每轮额外进行训练参考图库和验证集前向。默认模型是 ViT-L、368×640、24 层 LoRA。GPU 显存是否足够需在目标机器首批确认，显存不足可降低 batch（SupCon + PK 至少 4）或减少 LoRA blocks。

训练结束自动执行阶段 2，不需要先运行留一验证。需要逐组重训验证时再执行：

```bash
python script/4-留一型号验证.py --run output/oven/<run> --device cuda
```

当前有 3 个数据组，每折留出一个后仍有 2 个训练组，满足 SupCon 条件。默认每折与正式训练相同轮数，耗时相当于多次训练。若阶段 2 已用真实外部数据标定 tau，LOO 会保留该 tau；补充外部验证数据仍然必要。

数据预检报告：`output/preflight/data_check.json`。真实模型验证产物：`output/preflight/smoke_run/`。完整操作说明见 `script/0-使用方法.md`。
